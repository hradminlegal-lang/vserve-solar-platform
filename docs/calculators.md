# Calculators and engineering functions

Executable spec: `docs/calc-reference.js`. Expected outputs: `tests/golden/*.json` (generated by `node docs/make-golden.js`). `packages/calc` must pass every vector: tolerance 0.01 for decimals; exact for integers, strings, booleans, nulls; compare only keys present in `expected`; when `input` is an array, spread it as arguments.

## Engine rules
Pure, total (never throws), no I/O. Defaults come from a `CalcConfig` loaded from settings. Validation with zod schemas before calling. No rounding except `ceil` for panel counts, `floor` for fits, integer quote score.

## Customer calculators
| Function | What the customer learns |
| --- | --- |
| `billToSystem` | System size, panels, roof area, price range, savings, payback from a monthly bill |
| `applianceLoad` / `whatCanItRun` | What their appliances use, and what a given system can run |
| `batteryBackup` | Battery size for brownout backup |
| `financialModel` | 25-year savings with degradation, rate escalation, O&M and inverter replacement; payback, NPV, IRR, cost per kWh (LCOE) |
| `loanCompare` | Monthly payment, upfront cost, total cost and cash flow for each lender offer; eligibility by loan size |
| `affordability` | Indicative maximum monthly payment and loan from income and existing debts (lenders decide) |
| `loanVsSavings` | One loan vs savings, break-even month |
| `quoteScore` | How a proposal compares on price per kWp, sizing, production claim and documentation |
| `cleaningPayback` | When a cleaning pays for itself |

## Engineering functions (design studio and pro tools)
| Function | Use |
| --- | --- |
| `panelFit` | Panels that fit a rectangular plane with setbacks and gaps (portrait vs landscape) |
| `systemProduction` | Combine roof planes' simulated specific yield and shading into annual kWh |
| `inverterRatio` | DC/AC ratio check: < 1.0 undersized array, > 1.3 clipping risk |
| `stringSizing` | Min/max panels per string from temperature-corrected voltages; current check |
| `stringFuse` | Minimum fuse rating 1.56 × Isc; fuse needed from 3 parallel strings; module max series fuse check |
| `voltageDrop` | DC/AC drop and minimum standard cable size |
| `quoteMargin` | Price from cost and target margin, VAT, price per kWp check |
| `referralEarnings` | Partner commissions (phase 5) |

## Defaults (settings table, admin-editable, dated)
Rate ₱15.06/kWh (Meralco residential, Oct 2026) · yield 4.0 kWh/kWp/day (quick estimates only; designs use simulated yield) · panel 600 W, 2.6 m² · price range ₱50,000–70,000/kWp grid-tied · export credit ₱5.5/kWh · degradation 0.5%/yr · escalation 2%/yr · O&M inflation 3%/yr · discount rate 8% · max debt-to-income 35% (indicative).

Lender offers (rates, terms, minimum/maximum loan, down payment, fees) live in a `lender_products` table maintained by admin from each lender's published terms, each row with a source link and "checked on" date. Never hard-code a lender's rate.

A licensed electrical engineer must review the engineering functions and defaults (especially fuse rule and voltage-drop targets against the Philippine Electrical Code) before public launch.
